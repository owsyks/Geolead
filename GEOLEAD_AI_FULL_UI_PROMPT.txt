# GeoLead AI — Complete UI Design Prompt

> Build a full-stack SaaS dashboard for geo-domain investors. This prompt describes every screen, component, color, interaction, and data flow. Hand this to a designer or AI agent to reconstruct the entire interface.

---

## 1. PRODUCT SUMMARY

**GeoLead AI — "Find. Connect. Close."**

An AI-powered platform for geo-domain investors: discover local businesses (leads), enrich them with AI + LinkedIn intelligence, run compliant cold-email campaigns with rotating A/B variants, triage replies in a unified inbox, and manage a domain portfolio from acquisition to sale.

**Audience:** Domain investors owning hundreds to thousands of geo domains (e.g., MiamiRoofing.com, DallasPlumber.com).

---

## 2. DESIGN LANGUAGE

- **Style:** Modern dark-first SaaS dashboard. Clean, technical, "fintech / investment platform" energy.
- **Mood:** Confident, premium, data-dense but breathable. Subtle teal + copper accent glows, glassmorphism, rounded corners. Never playful or skeuomorphic.
- **Density:** High information density — small text sizes (10–14px), compact rows, many KPI tiles — organized into clearly bordered cards with generous internal padding.
- **Light & dark mode:** Both fully supported, dark mode is the hero. Theme toggle persists to localStorage.

### Colors

| Layer | Dark Mode | Light Mode |
|---|---|---|
| App background | `#0c0a09` warm coffee-black | `#ffffff` |
| Card/panel bg | `#1c1917` / `stone-900` glassy | `#fafaf9` warm cream |
| Borders | `#292524` subtle | `#e7e5e4` |
| Primary text | `#fafaf9` | `#0c0a09` |
| Muted text | `#a8a29e` | `#78716c` |
| **Brand accent** | **Teal** `#0d9488` → hover `#0f766e` | Same |
| **Secondary** | **Copper** `#d97706` | Same |
| **Gradient** | `linear-gradient(to right, #0d9488, #d97706)` | Same |
| **Glow** | `rgba(13, 148, 136, 0.15)` blurred | Same |
| Success / verified | Emerald `#059669` | Same |
| Warning / paused | Copper `#d97706` | Same |
| Danger / failed | Red `#dc2626` | Same |

### Typography

- **Font:** Geist (sans) for all UI; Geist Mono for code/emails.
- **Page titles:** `font-black` (900), 20–24px.
- **Body:** 14px default; 11–13px for metadata, labels, table cells.
- **Labels/eyebrows:** 11px, UPPERCASE, letter-spaced, muted.
- Antialiased, with stylistic ligature features enabled.

### Shape, Depth & Motion

- **Corners:** `rounded-lg` (8px) for cards/buttons, `rounded-2xl` (16px) for modals, `rounded-full` for pills.
- **Glassmorphism:** `.glass-card` — translucent bg + 16px backdrop blur + soft large shadow. Hover lifts with teal glow ring.
- **Shadows:** Soft and large (`0 8px 32px rgba(0,0,0,.37)`).
- **Ambient glow:** Blurred circular teal "glow-bg" blobs pulse slowly (8s ease-in-out).
- **Premium buttons:** Gradient border trick (dark fill + teal→copper border).
- **Transitions:** 0.3s cubic-bezier on hover.

## 5. PAGE-BY-PAGE SPECIFICATION

### 5.1 Overview (`/`) — "Outbound Command Center"

**Layout:** 3-column grid.

**Left column (2/3):**
- **Stats row:** 4 MetricCards — Campaigns, Active, Queued, Engagement Score %.
- **Hottest campaign card:** Name, domain, open rate %, click rate %, reply rate %. Link to Campaigns.
- **Top leads card:** 8 rows — business name, email count, domain match %, priority score. Link to Lead Explorer.

**Right column (1/3):**
- **Live Activity feed:** Real-time WebSocket + REST events. Each card shows:
  - Color-coded event type badge (OPENED = emerald, BOUNCED = red, CLICKED = teal, UNSUBSCRIBED = amber)
  - Variant letter (A-E in teal badge)
  - Campaign name
  - Business name · email address
  - Subject line (truncated)
  - Timestamp (relative)
  - Max 8 items, newest first.
- **Deliverability Alerts:** Amber-tinted cards with actionable warnings (SPF/DKIM needed, bounce rate high).

**Empty state:** "No campaigns yet. Create one to start scheduling respectful outreach."

### 5.2 Portfolio (`/portfolio`)

**Header:** "Domain Portfolio" + [Add Domain] [Import] [Export] buttons.

**Stats row:** Total domains, Portfolio value, Investment, Revenue, Profit, ROI, Expiring, Active campaigns, Leads, Replies, Domains sold.

**Domain list:** Filterable table with columns:
- Domain name (bold), Status (pill badge), Purchase date/price, Registrar, Expiration, Category, Niche, Branding score, Estimated value, Buyer demand, Tags.
- Row actions: Edit (inline), Archive, Record sale.
- Bulk actions: select multiple → change status, add tag.

**Add/Edit Domain modal:** Name, Status dropdown (Available/Prospecting/Contacting Buyers/Negotiating/Sold/Archived), Purchase date, Purchase price, Registrar, Expiration date, Category, Niche, Industry, City/State/Country, Tags, Target industries, Target locations, Notes.

**Import:** CSV/TXT/JSON upload with field mapping.

**Filters:** Search (name/tags), Status dropdown, Category dropdown, Sort by (name, value, date, score).

### 5.3 Sales Kanban (`/portfolio/kanban`)

**6 drag-and-drop columns:** Available → Prospecting → Contacting Buyers → Negotiating → Sold → Archived.

Each card shows: domain name, niche, estimated value badge, lead count.

Drag a card to move it; status syncs across the entire app.

### 5.4 Acquisition Advisor (`/acquisition`)

**Input:** Paste domain list (newline/comma separated, max 100). Bulk scan button.

**Results:** 5 tiers color-coded — STRONG_BUY (emerald), BUY (teal), WATCHLIST (amber), SPECULATIVE (slate), AVOID (red).

Each result card: domain name, tier badge, AI reasoning paragraph. Expand for full analysis. Action buttons: Add to portfolio, Add to watchlist.

**Investor Chat:** Per-domain AI chat input — ask "What's this domain worth?", "Who would buy this?", "What's the exit strategy?"

### 5.5 Watchlist (`/watchlist`)

**Tabs:** All / Available / High Priority / Reminders / Notifications.

**Domain list:** domain name, priority (CRITICAL/HIGH/MEDIUM/LOW) color-coded dot, AI recommendation (BUY_NOW/WAIT/MONITOR/AVOID) badge, registration status, registrar, expiration date, last checked.

**Actions per domain:** Check DNS now, Add reminder, Move to portfolio.

**Reminders panel:** Configure triggers (time-based days, status change, availability). Notify via IN_APP/EMAIL/BOTH.

**Notifications panel:** Read/unread list, priority levels (URGENT/HIGH/NORMAL), mark all read button.

## 6. GLOBAL BEHAVIORS

### Notifications
- Bell icon in header with red unread count badge.
- Polls `/api/watchlist/notifications/unread-count` every 60s.
- Desktop notifications via Web Notification API for new replies.

### WebSocket (`/ws/outbound`)
- Custom raw WebSocket implementation (no library).
- Events broadcast: CAMPAIGN_STATUS, CAMPAIGN_DELETED, EMAILS_QUEUED, INBOX_SYNCED, NEW_REPLY, SENT, OPENED, CLICKED, BOUNCED.
- Each event carries: emailLogId, campaignId, toEmail, subject, variant, businessName.
- Frontend merges WS events into Live Activity feed (capped at 8).
- Overview page connects on mount, auto-reconnects on error.

### Polling
- Lead search task progress: polls every 3s while PENDING/PROCESSING.
- Email verification progress: polls every 300ms for streaming token.
- Email verification job: polls every 2s for queued jobs.
- Acquisition scan: polls every 3s for up to 4 min.
- Watchlist notifications: polls every 60s.

### Offline/Demo Fallback
- Every data-fetching page catches errors and falls back to hardcoded demo data.
- Amber banner: "Backend offline. Showing demo data."
- [Retry Connection] button re-fetches.

### Rate Limiting
- In-memory fixed-window per-endpoint buckets.
- `/api/leads`: 300/10min. `/api/export`: 20/10min. `/api/email/verify`: 120/10min.
- Frontend respects limits by reducing polling frequency.

### Compliance
- Every outgoing email includes: physical mailing address, unsubscribe link, truthful sender identity.
- Opt-out tracking: unsubscribe tokens in every email.
- Suppression list: bounced and unsubscribed emails are permanently blocked.
- Campaign guardrails card in sidebar: "Opt-outs, sender limits, suppression checks, and truthful cold-email copy are enforced by default."
